# blockdyor Community App Store for umbrelOS

To install an app from this store, open the App Store on your Umbrel, choose Community App Stores, and add this repository URL:

```text
https://github.com/blockdyor/blockdyor-umbrel-community-app-store
```

Select **Bassin** in the blockdyor store. It requires a synchronized Bitcoin node. The [community manifest](blockdyor-bassin/umbrel-app.yml) lists the version and release notes; [Docker Compose](blockdyor-bassin/docker-compose.yml) pins the images it installs. The [official Umbrel listing](https://apps.umbrel.com/app/bassin) is a separate release channel and may offer a different version.

This store also includes [Memos](blockdyor-memos/umbrel-app.yml).
